[Jason Grigsby put words to something I’ve been trying to sort out](https://cloudfour.com/thinks/improvements-to-web-for-ai-should-benefit-all-users/). If the industry is going to add richer semantics so AI agents can understand and operate websites, those improvements should reach people and assistive technology, too. User needs come first; agents shouldn’t get a more legible, operable web while keyboard and screen-reader users are left with the old gaps.

<blockquote cite="https://cloudfour.com/thinks/improvements-to-web-for-ai-should-benefit-all-users/">

> The proposal says WebMCP “is not designed for ingestion by accessibility technology”, the same fork: richer, actionable semantics reach agents while screen-reader and keyboard users get less.

</blockquote>

Jason’s discussion of HTML, ARIA, and the W3C’s Priority of Constituencies is worth reading in full. It crystallized why a separate, agent-only layer feels backward to me: we should first improve the shared layer that people, assistive technology, and agents already use.
